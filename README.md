# Max Pfennighaus

I’m a designer and creative director interested in how identity, editorial thinking, digital products, and systems can make complicated things clearer.

For more than 25 years I’ve moved between strategy and making, leading work at Johnson & Johnson, The New York Times, NPR, Synchrony, and elsewhere. The projects here are a more recent part of that practice: small publishing systems, privacy-minded tools, product prototypes, and generative experiments—often made with AI as a collaborator.

## Selected work

- **[Thinkinghaus](https://github.com/mxpf/thinkinghaus)** — an AI-assisted writing practice and the quiet publishing system built around it.
- **[Make Placid](https://github.com/mxpf/make-placid-portfolio)** — a content-led portfolio template organized around a small, consistent set of editorial rules.
- **[Trackinghaus](https://github.com/mxpf/trackinghaus)** — self-hosted, privacy-minded analytics that turns aggregate reading data into one useful weekly observation.
- **[Personal Reading Archive](https://github.com/mxpf/print-archive-reader)** — a mobile-first prototype for capturing, correcting, organizing, and reading a personal print library.
- **[Flow Field Dashes](https://github.com/mxpf/flow-field-dashes)** and **[Tiny House Generator](https://github.com/mxpf/tiny-house-generator)** — two small generative systems for staying close to visual play.

The code is part of the work, but not the whole point. I’m usually testing a way of seeing, organizing, or making something before I’m testing a technology.
